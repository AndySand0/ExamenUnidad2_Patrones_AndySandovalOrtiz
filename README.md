Organizacion y gestion de eventos academicos
Se desarrollo un sistema para gestionar salones de eventos académicos donde se controla su estado y el tipo de evento asignado utilizando una clase singleton para manejar la lógica del menú principal y un pool de objetos para administrar una lista de salones permitiendo asignar salones disponibles, liberar los ocupados y simular su limpieza antes de volver a estar disponibles, todo esto mediante un menú interactivo en consola
